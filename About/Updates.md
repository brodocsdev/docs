
## Scheduled updates and notifications

Every site is updated within few minutes if there are any changes if repo. If repo is private, the key provided during init will be used. If you are in hurry, you may always send pull with siteId:


```plain
https://brodocs.io/api/sites/ef1.../pull
```



Or configure your repo provider notification to call it after push, e.g. Webhook in GitHub.
