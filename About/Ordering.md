## Order files

The elements in given directory are ordered in natural sort order, both directories and files, directories come first. If you want to change the order in given directory, create simple text file with name order and list elements which should go first, e.g. [brodocsdev/docs/order](https://github.com/brodocsdev/docs/blob/main/order): 

```plain
README.md
Quick start.md
```

The order from this file will be applied first, then go rest of files in natural sort order.
